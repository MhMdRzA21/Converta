Frequently asked questions

Why does PDF-to-Word conversion sometimes come out messy?

When a PDF was built from a scanned page — which is really just an image — it has no selectable text, so the conversion can't reconstruct the words accurately. PDFs exported from Word or similar software convert much more cleanly.

Does anyone see my file?

No. Your file only stays on the server for the duration of processing and is deleted immediately after the result is handed back. Full details are in the privacy policy.

Why was my file rejected?

Usually one of a few reasons: the file is over 25MB, it's corrupted or incomplete, or the target format isn't supported for that file type (for example, a password-protected file).

Is there a daily limit on conversions?

To prevent automated abuse, the number of requests from a single IP address is limited over short windows. For normal day-to-day use, you won't come close to that limit.

Can I convert several files at once?

For image format conversion and building a PDF from images, yes — up to 20 files per batch. For PDF-to-image and Office document conversion, one file at a time.
