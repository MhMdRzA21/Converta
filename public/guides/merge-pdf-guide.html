How to Merge Multiple PDFs Into One File

A step-by-step guide, plus what to double-check

Merging PDFs comes up constantly in ordinary work: combining a cover letter with a resume, stitching together scanned receipts for an expense report, or assembling a set of signed contract pages into a single document to send. It's a simple operation, but a few small details decide whether the result is exactly what you expect.

Step by step

  1. Gather your PDFs in one place. Know exactly which files you're combining and, just as importantly, the order you want them to appear in.
  2. Add them to a merge tool — for example, our Merge PDF tool — in the order you want them to end up in. Most merge tools, including this one, combine files in the exact order you add or drop them.
  3. Double-check the order before converting. This is the step people skip and regret — if you added files out of sequence, reorder or remove and re-add them before merging, since fixing page order after the fact means re-doing the merge.
  4. Merge and download. The result is a single PDF with every page from every source file, in sequence.
  5. Open the merged file and skim through it. Confirm every source document made it in, in the right order, and that nothing looks cut off or duplicated.

Things worth checking beforehand

  • Password-protected PDFs. A merge tool generally can't read a PDF that's locked with a password — you'll need to remove the password (in the program that created it, or a PDF editor) before merging.
  • Page orientation. If one source file has landscape pages mixed with portrait pages, that mix carries over into the merged file as-is — merging doesn't rotate or normalize pages for you.
  • File size. Merging doesn't compress anything; the merged file's size is roughly the sum of its parts. If you're merging many large PDFs (especially scanned ones), expect a correspondingly large result.

Does merging affect quality?

No — a proper merge tool copies each page into the new file exactly as it was, without re-rendering, re-compressing, or otherwise touching the content. If your source PDFs look sharp, the merged file will too. This is different from, say, converting a PDF to an image and back, which can introduce quality loss; merging just repackages existing pages side by side.

A common mix-up: merge vs. combine into one page

Merging PDFs means keeping every page as its own page, just in one continuous file — a 3-page and a 5-page PDF become one 8-page PDF. It's not the same as overlaying documents on top of each other or squeezing multiple documents onto a single sheet, which is a different (and much less common) operation. If what you actually want is to place several pages side-by-side on one printed sheet, that's a print-layout setting, not a merge.
