DOCX vs. DOC vs. ODT: What's the Difference?

Three formats, three different documents under the hood

They all open as an editable word processor document, and to a casual glance they look the same. But DOCX, DOC, and ODT are built on genuinely different underlying technology, and knowing which is which helps explain the occasional formatting hiccup when you move between them.

DOC — the old Microsoft format

DOC was Microsoft Word's default file format from Word 97 through Word 2003. It stores a document in a binary format — data packed in a way that's efficient for the program to read but isn't human-readable and is harder for other software to interpret correctly. Because it's a closed, binary format, DOC files can occasionally lose minor formatting fidelity when opened in non-Microsoft software. It's largely been superseded, but you'll still run into DOC files from older archives, templates, or institutions slow to update their systems.

DOCX — the modern Microsoft format

Since Word 2007, DOCX has been the default. The key difference from DOC isn't just the extra letter — DOCX is actually a zip archive containing a set of XML files describing the document's text, formatting, and structure. Being XML-based (and openly documented, under the Office Open XML standard) means other software can parse it much more reliably than the old binary DOC format. This is why DOCX has become the de facto standard that most word processors — including free ones — read and write natively today.

ODT — the open standard

ODT (OpenDocument Text) is the default format for LibreOffice Writer and OpenOffice Writer. Like DOCX, it's XML-based and zip-packaged, but it follows a different specification — the OpenDocument Format, an open standard maintained independently of any single company, originally developed by Sun Microsystems and now overseen by OASIS. Functionally, it does the same job as DOCX: paragraphs, styles, images, tables. The main reason to encounter ODT is that it's what LibreOffice and OpenOffice save to by default, and some government and public-sector organizations mandate it specifically because it's a vendor-neutral open standard.

Do they actually convert cleanly between each other?

For everyday documents — reports, letters, forms — conversion between all three is generally reliable, since the underlying concepts (paragraphs, headings, tables, images) map closely across formats. Where you can see small shifts is in less common formatting: specific font substitutions if a font isn't available on the system doing the conversion, unusual spacing or indentation rules, or advanced features tied closely to one program, like Word-specific macros or ODT-specific style inheritance. For the vast majority of documents, these are minor and easy to spot-check rather than dealbreakers.

Which one should you use?

  • Sending a document to someone using Microsoft Word → DOCX. It's the most universally supported format today.
  • Working exclusively in LibreOffice or OpenOffice → ODT is a fine default, but export to DOCX before sharing with Word users.
  • Received an old DOC file and need to edit it → open and re-save as DOCX to bring it up to the modern format.
  • Government or institutional requirement → follow whatever format they specify; it's often ODT for open-standard compliance reasons.
